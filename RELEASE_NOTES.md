# OpenBRender 0.1.0 — open-source snapshot, 2026-10-07

This release packages the current local browser editor, including the SVG artwork
editor, scientific drawing tools, editable charts, local save/recovery, 583 licensed
drawings, bundled fonts, portable examples, source code, tests and a production build.
The application version remains 0.1.0; the dated archive identifies this snapshot.

Only explicitly selected product, source, test, licence and documentation files
are distributed. Local logs, browser profiles, generated reports, caches, dependency
installations, credentials, agent configuration, machine-specific helpers and
previous release archives are excluded. Public third-party credits and required
licence notices are retained.

This is a local evaluation distribution, without native installers, hosted release
attestations or public-provider deployment claims. Browser printing, scientific
review and publication-rights assessment retain the limitations described in README.
