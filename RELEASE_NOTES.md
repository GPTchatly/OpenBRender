# OpenBRender 0.1.0 — open-source snapshot, 2026-10-08

This release packages the current local browser editor, including the SVG artwork
editor, scientific drawing tools, editable charts, local save/recovery, 2,665 licensed
drawings, bundled fonts, portable examples, source code and a production build.
The application version remains 0.1.0; the date identifies this snapshot.

## Main changes since 2026-10-07

- The library grows from 583 to 2,665 drawings across 39 categories: 1,352 Servier
  Medical Art drawings (CC BY 3.0, vector edition via Bioicons) and 706 NIH BioArt
  Source drawings (701 public domain, 5 CC BY 4.0) join the Bioicons set.
- The editor renders drawings with blended, isolated or nested-clipped layers as
  browsers do, and SVG export keeps the blending.
- Category shelves show every drawing in the category, NIH BioArt drawings first.
- New figure: one click on a format or template opens it.
- The License tab lists only each drawing's license and any credit it requires;
  the publication check, figure preflight and publication report are removed.

Only explicitly selected product, source, licence and documentation files
are distributed. Local logs, browser profiles, generated reports, caches, dependency
installations, credentials, agent configuration, machine-specific helpers and
previous release archives are excluded. Public third-party credits and required
licence notices are retained.

This is a local evaluation distribution, without native installers, hosted release
attestations or public-provider deployment claims. Browser printing, scientific
review and publication-rights assessment retain the limitations described in README.
