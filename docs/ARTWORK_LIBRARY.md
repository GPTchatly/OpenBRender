# Scientific drawing library

The local release contains **2,665 drawings across 39 categories**, up from 583: 607 Bioicons drawings (**314 CC0** and **293 CC BY 4.0**), 1,352 Servier Medical Art drawings (**CC BY 3.0**) and 706 NIH BioArt Source drawings (**701 public domain** and **5 CC BY 4.0**). Some drawings are variants; these counts do not represent 2,665 distinct scientific concepts.

The Bioicons source is revision `d29e766ea7580b8063c4f47b29e872db40a4d979`, acquired through the pinned OpenBioFigure snapshot `8f72679efc26c821737cc3adb2ddca033150f06e`. An additional 137 candidates were acquired directly from the same pinned Bioicons revision with matching per-icon license metadata and verified Git blob bytes. Each record retains its source URL, creator, license URL, attribution, original SHA-256, upstream Git blob or source file identifier, and normalization notes.

## NIH BioArt Source

[NIH BioArt Source](https://bioart.niaid.nih.gov/terms) states that its illustrations are "free for any use, including educational, research, informational, and commercial purposes", and that each entry carries its own license. The acquisition reads the catalogue through the site's own search, reads the license on every entry page and cross-checks it against the catalogue, then downloads the entry's SVG from `/api/bioarts/<entry>/files/<file>`. Public Domain entries are recorded as `Public-Domain` (citation appreciated, not required); CC BY entries (the Human Reference Atlas collection) as `CC-BY-4.0` with required attribution. Credits use the site's citation format: `<Collection>. (<date>). <Title>. NIAID NIH BioArt Source. bioart.niaid.nih.gov/bioart/<entry>`. The terms as retrieved are kept in /licenses/artwork-nih-bioart.txt.

Entries publish many recolored copies of one drawing ("Antibody - Blue"); only the original rendering is acquired, because the artwork editor recolors parts. Identical files published under several entries are kept once, under the earliest entry. SVGs over 2 MB are skipped. Many NIH drawings blend layers (multiply, overlay, color and other CSS blend modes) and nest clipping paths. The editor renders both as browsers do: a blended, isolated or clipped group composites as one layer, and SVG export writes the blending back. Screening compares each such drawing with Chromium's own rendering, in the editor and as exported SVG, and excludes any that differ in more than 5% of inked areas. Drawings with embedded raster images, filters, masks, patterns or clipping inside clip paths are excluded rather than altered. Five CC BY Human Reference Atlas drawings pass; the rest are excluded.

## Servier Medical Art

smart.servier.com licenses its images under CC BY 4.0, but it offers only PNG and PPTX files, and its terms of use prohibit automated access ("Not use automated methods (bots, scrapers, etc.) to access or download Site Content"). The library therefore uses the SVG vector edition of Servier drawings published in the same pinned Bioicons revision under **CC BY 3.0 Unported**, verified against each upstream Git blob. Servier's FAQ allows SMART images in apps "as long as it's not marketed as a standalone image library": describe OpenBRender as a figure editor, not as an image bank. Credits read `<Title> by Servier Medical Art (https://smart.servier.com/), vector edition distributed via Bioicons, licensed under CC BY 3.0 Unported (https://creativecommons.org/licenses/by/3.0/).` The license text is in /licenses/artwork-cc-by-3.0.txt.

All approved library SVGs are files under **app/public-browser/artwork**, Vite's configured public directory. The build copies them to dist/artwork and serves them as **/artwork/<sha256>.svg**. The application ships a metadata manifest rather than SVG bodies in its JavaScript bundle. Thumbnails load lazily; insertion fetches only an application-owned manifest path and verifies its byte hash and supported SVG structure. Private document artwork stays embedded locally and is never uploaded to this directory.

These immutable filenames receive one-year public cache headers. The shell revalidates, and errors must bypass CDN caching. See HOSTING.md for Cloudflare configuration and the live cache checks still required.

The Bioicons acquisition contains 869 verified non-Servier candidates; structural/provenance checks and actual browser renderer/export screening exclude 262. The same checks exclude 20 of 1,372 Servier candidates and 190 of 896 NIH candidates. Three other candidates failed upstream Git blob verification and were rejected before ingestion. Maintainer normalization expands simple class and inline styles, local gradient templates and non-rendering authoring metadata; it preserves geometry and records changes. Unsupported filters, raster content, complex clipping, external resources and invalid/over-budget exports remain excluded. The runtime policy for private SVGs does not accept arbitrary source stylesheets or editor extensions.

Every shipped drawing is checked for native SVG rendering, actual Fabric grouping, non-empty pixels, and validated standalone SVG export in Chromium. This is compatibility and provenance evidence, not an independent scientific-curation verdict. Authors must check the biological meaning, labels and suitability of each illustration. Historical screening logs are excluded from the public package. The included unit tests recheck every shipped SVG and its provenance; the optional library browser test can reproduce renderer/export checks and writes a fresh reports/library-browser.json. Previous-release provenance bindings remain available for already saved portable projects.

CC BY artwork requires attribution. The License tab generates credits; keep them with publications, especially PNG and PDF exports. SVG metadata and portable project files include source, license and modification records. Full retained artwork credits are in the built /licenses/third-party.txt file.

The library panel shows every drawing on category shelves grouped under eight topics. Each shelf opens to all of its drawings, and its header stays pinned while they scroll. Search, topic, category and licence filters narrow the shelves (opened automatically), and favorites and recent artwork use the same shelves. Search terms include amino acid, antibody, neuron, mouse, DNA, microscope, plants, mitochondria, virus and cell.

The CC0 incubator by KeHan is a documented vector adaptation: three blurred gloss highlights become plain vector highlights, while equipment geometry is retained. Only the exact reviewed source hash is eligible for this conversion; private SVG imports still reject filters. Additional source evidence is in docs/audit/supplemental-artwork-source.json and supplemental-artwork-records.json.

The default Scientific drawing DNA tool now creates two connected opposing backbones with paired rungs, all native editable lines. Favorites and recent artwork are stored in browser localStorage; projects and recovery copies are in local IndexedDB. They are not sent to a server.
