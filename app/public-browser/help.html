OpenBRender 0.1.0

Create and edit scientific figures locally, without an account or uploads.

Create and edit

Choose New figure or a starter template. Add text, shapes and arrows from the toolbar. Double-click text to edit. Drag objects and resize with their handles. Shift-click selects several objects; the Style inspector edits position, size, color and rotation.

Expand Scientific drawing in the library for cells, membranes, DNA, panels, scale bars and editable charts. Browse 583 drawings across 33 categories, filter by topic or license, and use Show more to load additional results. CC BY artwork requires attribution: download credits from License and keep them with PNG/PDF publications. Check each illustration's scientific suitability. Scale-bar values and example chart data need author review.

Save and recover

Edits autosave in this browser. Wait for Saved locally. Download a portable project backup with Save project file; its artwork and provenance travel with it. Browser storage belongs to this address and port, and can be cleared or exhausted. If a save fails, download the project before closing.

Export

SVG preserves vectors and live text. PNG exports document pixels at the chosen 1–4× scale. PDF opens the browser print dialog: choose Save as PDF, 100% scale, no margins and no headers/footers. Chrome/Edge honor the figure page size at 96 pixels per inch.

Rights and safe imports

The License panel shows rights records and exports credit/publication reports. Private SVG imports stay unreviewed. Supply known creator, source and license information; the app does not infer permission. Unsupported SVG effects, scripts and external resources are rejected before insertion.

Shortcuts

  • Ctrl+S: download portable project
  • Ctrl+Z / Ctrl+Shift+Z: undo / redo
  • Ctrl+C / Ctrl+V / Ctrl+D: copy / paste / duplicate selection
  • Ctrl+G / Ctrl+Shift+G: group / ungroup
  • Delete: remove selection
  • Arrow keys: nudge; Shift+arrows: ten-pixel nudge
  • Space: pan; 0: fit to screen

Local distribution

Keep the local server window open. The built folder runs without internet with Node.js 24.11 or newer. Copy the complete distribution and portable projects to another computer for offline use. This release has no service-worker installation or automatic update system.
