# M0 reference documents

These five portable .obf.json documents use inherited native shapes and templates. The plot contains explicitly synthetic values. They contain no admitted third-party artwork, photographs or biological measurements.

They are positive controls for model validation and later editing/export tests. They have not passed researcher usability, visual fidelity, scientific review, calibration or publication acceptance. The microscopy workflow still requires safe raster import.

Regenerate from the workspace root with: node --import ./tests/register-source.mjs scripts/create-reference-projects.mjs. Regeneration creates fresh IDs and dates.
